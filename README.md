## ✨ Overview

HushPay is a privacy-first payment protocol that enables users to send and receive payments using simple SMS messages.

No smartphones.  
No banking apps.  
No internet connection required.

Built on Solana and secured with Zero-Knowledge (ZK) proofs, HushPay brings fast, private, and accessible payments to anyone with a mobile phone.

## 🔐 Why HushPay?

Traditional crypto payments require:
- Smartphones
- Internet access
- Wallet installations
- Technical knowledge

HushPay removes those barriers by turning SMS into a private financial layer powered by blockchain infrastructure.

This creates:
- Financial accessibility
- Privacy-preserving transfers
- Low-friction onboarding
- Global payment reach

---

## ⚙️ How It Works

1. User sends an SMS command
2. HushPay validates the request
3. ZK proofs verify transaction integrity
4. Settlement occurs on Solana
5. Recipient receives confirmation via SMS

Example:

```bash
SEND 10 USDC TO +628123456789
```
